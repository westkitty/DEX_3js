# Museum of Me profile

Choose the existing Museum source checkout in DEX 3js. Do not copy it into DEX 3js. Existing source and authoring contracts remain owned by the Museum repository.

Select Museum of Me with the folder picker, then choose **Import profile…** and select `profiles/museum-of-me.json` from this repository. The example uses the current Vite default `127.0.0.1:5173`; update the profile if Vite chooses a different port. The paths were checked against the active Museum README and entry point on 2026-11-04: play, Workshop (`?edit=1`), Free Flight (`?devtools=1`), interior workbench, Full Island (`/workbench/?view=island`), Visitor Choreographer (`?choreo=1`), and `?qa=1` startup timing. Browser Diagnostics here means the browser-hosted dev view with console startup timing; it does not open remote debugging or fabricate FPS/GPU metrics.

Three.js DevTools MCP and Studio remain shared user-level installs. Confirm connections within each desktop client's local project session. The launcher does not claim live scene connectivity from server startup.
